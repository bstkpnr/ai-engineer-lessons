# Gün 2: LLM'ler aslında nasıl çalışıyor?

📖 Yazı: [AI Engineer Oluyoruz — Gün 2](https://medium.com/@bstkpnr/ai-engineer-oluyoruz-g%C3%BCn-2-llmler-asl%C4%B1nda-nas%C4%B1l-%C3%A7al%C4%B1%C5%9F%C4%B1yor-64bc8b1a2598)

| Dosya | Deney | Komut |
|---|---|---|
| `tokens.mjs` | Türkçe ve İngilizce kaç token tutuyor? | `npm run tokens` |
| `temperature.mjs` | Temperature farkını gözle görmek | `npm run temperature` |
| `limit.mjs` | max_tokens sınırına çarpmak | `npm run limit` |
| `memory.mjs` | Model gerçekten hafızasız mı? | `npm run memory` |

## Çalıştırma

```bash
npm install
npm run tokens
```

> API anahtarının ana klasördeki `.env` dosyasında olması gerekiyor. Ayrıntılar için [ana README](../README.md)'ye bak.
